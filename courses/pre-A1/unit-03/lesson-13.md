# 🌍 Kraje i narodowości

Poznaj narodowości odpowiadające krajom z Lesson 11.

**Poland — Polish**  
**Spain — Spanish**  
**Italy — Italian**  
**France — French**  
**Germany — German**  
**Portugal — Portuguese**  
**Ukraine — Ukrainian**  
**the UK — British**  
**the USA — American**  
**Canada — Canadian**  
**Mexico — Mexican**  
**Japan — Japanese**

Nie próbuj tworzyć tych słów samodzielnie według jednej reguły.

Spójrz:

**Poland → Polish**

ale:

**Italy → Italian**

i:

**France → French**

Narodowości mają różne formy.

Na tym etapie najlepiej poznawać **kraj i narodowość razem**.

# ✅ Potrafię

Po tej lekcji:

- [ ] Rozumiem różnicę między **country** i **nationality**.
- [ ] Znam narodowości odpowiadające poznanym krajom.
- [ ] Potrafię powiedzieć **I'm Polish / Spanish / Italian...**
- [ ] Rozumiem różnicę między **I'm from Poland** i **I'm Polish**.
- [ ] Pamiętam wzór **I'm from + country**.
- [ ] Pamiętam wzór **I'm + nationality**.
- [ ] Wiem, że **the UK → British**.
- [ ] Wiem, że **the USA → American**.
- [ ] Potrafię podać swój kraj i narodowość.

### Następna lekcja

Do tej pory mówiłeś głównie o sobie:

**I'm from Poland.**

**I'm Polish.**

W następnej lekcji poznasz **he** i **she** i zaczniesz mówić również o innych osobach.
